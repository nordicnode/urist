and regenerate.

## Generated stubs

The `*_pb2.py` files next to them are generated by
`scripts/generate_protos.py` (protoc via grpcio-tools, installed in the
project venv at `.venv/`). The generator rewrites the two flat cross-file
imports protoc emits into package-relative imports — see the script header
for why. Regenerate with:

```
.venv/bin/python scripts/generate_protos.py
```

Runtime dependency: `protobuf` only (`protobuf>=5`). `grpcio-tools` is
needed only to regenerate.
